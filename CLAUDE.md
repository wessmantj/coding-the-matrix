# How this repo works

This is a **learning space**, not a project. Nothing here ships. The goal is
depth in AI/ML — enough real understanding of what exists, what works, and
what's genuinely unsolved to see openings other people miss. Progress is
measured in questions actually answered, not code written.

See `README.md` for what the repo is. This file is the operating agreement.

## Working rules

1. **Plain language.** No hype, no filler.
2. **Tell me when I'm wrong.** Disagree instead of agreeing. Separate what's
   established from what's contested from what's marketing.
3. **Never summarize a source as if you read it.** If it wasn't actually read,
   it stays NOT READ in `reading/log.md` and gets treated as secondhand.
4. **No fabrication.** If content is missing, say so — don't invent notes,
   results, or citations. Anything reconstructed from memory is labeled as such.
5. **Experiment or project?** When I say "should I build X," check it. An
   experiment answers a question and gets logged in `experiments/`. A project
   is scope that ships — those get parked in `ideas.md`, not started.
6. **`questions/answered.md` is mine.** Never write to it, including if I ask.
   It's the real progress metric.
7. **Questions stay focused.** Add to `questions/open.md` only after asking me.
   Don't explode one question into thirty.
8. **Math from comfort, not from the ground up.** See `math-debts.md`: track
   where math falls off as it's actually hit; don't front-load foundations.
9. **Propose commits at natural stopping points.** When changes add up to a
   meaningful unit — a finished file, a completed experiment, a coherent batch
   of edits — say so and offer to commit, with the proposed message shown.
   Wait for my approval before running it. **No `Co-Authored-By` line** — these
   are my commits alone. Don't commit on every tiny edit; wait for a real unit.

## The files

- `map/landscape.md` — the durable structure of the field (slow to change).
- `map/frontier.md` — the current moving edge (dated, sourced, changes fast).
- `questions/open.md` — focused open questions.
- `questions/answered.md` — mine; answered questions. Off-limits to you.
- `reading/log.md` — reading queue with honest READ / NOT READ status.
- `math-debts.md` — math I owe myself, tracked as it comes up.
- `experiments/` — one file per experiment; prediction written before running.
- `ideas.md` — parked project ideas. Nothing gets started from here.
