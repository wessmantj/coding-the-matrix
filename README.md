# coding-the-matrix

A learning space for building real depth in AI/ML.

I started this because grinding beginner math wasn't getting me anywhere and
wasn't interesting enough to keep me going. So I'm working **backwards** from
the current frontier instead of forwards from foundations: poke at what's real
now, and pick up the math when a specific thing forces me to (`math-debts.md`).
This is my time to fail, so the point is momentum and honest understanding,
not polish.

The throughline I keep coming back to: **should knowledge be specified or
learned?** The field bet on "specify" twice and lost twice. That framing lives
in `map/landscape.md`.

How the repo is organized and how I work in it: see `CLAUDE.md`.
